La planification est la clé de la réussite en course à pied. Ne partez plus trop vite : sachez exactement quelle allure tenir pour franchir la ligne d'arrivée dans le temps imparti.

Politique de confidentialité

Application concernée

Running Speed Calculator

Dernière mise à jour : mars 2026

1. Objet

Cette politique décrit les traitements de données applicables à Running Speed Calculator, développée par Benjamin Wolff.

2. Données collectées

Running Speed Calculator ne collecte aucune donnée personnelle à distance. Aucun compte utilisateur, aucune transmission vers un serveur.

Aucune donnée de localisation, de santé ou d'activité n'est lue ou communiquée.

3. Stockage local

L'historique de calculs (mode Pro) est stocké localement sur l'appareil via les mécanismes standard d'iOS.

4. Achats intégrés

L'achat intégré unique pour le mode Pro est géré par Apple via StoreKit. Aucune donnée bancaire n'est accessible au développeur.

5. Services tiers

Aucun SDK publicitaire, aucun analytics tiers, aucun service externe de suivi. Le seul service tiers est l'infrastructure d'achat d'Apple.

6. Mineurs

L'application n'est pas spécifiquement destinée aux enfants. Ne collectant pas de données, aucun traitement particulier n'est mis en place.

7. Modifications

Cette politique peut être mise à jour. La date figure en tête de cette section.

Support

Questions fréquentes

Mes données sont-elles envoyées quelque part ?
Non. Aucune donnée personnelle n'est transmise. L'historique Pro reste sur l'appareil.
L'application est-elle payante ?
Gratuite. Un achat intégré unique à 2,99 € débloque le mode Pro.
Problème d'affichage, que faire ?
Fermez puis rouvrez l'app, vérifiez qu'iOS est à jour. Si le problème persiste, contactez le support.
Comment demander un remboursement ?
Les remboursements sont gérés par Apple via reportaproblem.apple.com.
